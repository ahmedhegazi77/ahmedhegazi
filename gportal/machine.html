🤔 تعلم الآلة هو أحد فروع الذكاء الاصطناعي الذي يهدف إلى جعل الحاسوب يتعلم من البيانات بدلاً من كتابة الأوامر بشكل مباشر.

📊 بدلاً من برمجة كل القواعد يدوياً، نقوم بتزويد الحاسوب ببيانات كثيرة ليكتشف الأنماط ويستنتج القواعد بنفسه.

💡 مثال عملي: تصنيف البريد العشوائي
  1. البيانات: 10,000 رسالة بريد إلكتروني، نصفها عشوائي ونصفها عادي
  2. التدريب: نستخدم 80% من البيانات لتدريب نموذج تعلم الآلة (مثال: خوارزمية Naive Bayes)
  3. الاختبار: نستخدم 20% المتبقية لاختبار دقة النموذج
  4. النتيجة: نموذج قادر على تصنيف البريد العشوائي بدقة تصل إلى 98%

📝 استخدام النتيجة في برنامج

بعد تدريب النموذج، يمكننا استخدامه في برنامج بسيط:

def تصنيف_البريد(نص_الرسالة):
    # نموذج مدرب مسبقاً
    if نموذج.توقع(نص_الرسالة) == "عشوائي":
        return "⚠️ هذه الرسالة عشوائي - احذفيها"
    else:
        return "✅ بريد عادي - آمن للقراءة"

# مثال استخدام
بريد_جديد = "عرض خاص: اربحي 10000 دولار!"
print(تصنيف_البريد(بريد_جديد))

📌 هناك ثلاثة أنواع رئيسية لتعلم الآلة، ولكل نوع استخداماته المميزة:

📊 التعلم الموجه (Supervised Learning)

تعلم يعتمد على بيانات معروفة النتائج (مثل: تصنيف الصور، توقع الأسعار)

مثال: تصنيف الفواكه (تفاح/برتقال) بناءً على اللون والحجم
🔍 التعلم غير الموجه (Unsupervised Learning)

تحليل البيانات واكتشاف الأنماط بدون إجابات مسبقة (مثل: تجزئة العملاء)

مثال: تقسيم عملاء متجر إلكتروني إلى مجموعات متشابهة لاستهدافهم بعروض مخصصة

💻 برنامج تجزئة العملاء (مثال مبسط)

# استخدام مكتبة scikit-learn
from sklearn.cluster import KMeans
import pandas as pd

# بيانات العملاء (المشتريات، التكرار، ...)
بيانات = pd.read_csv("عملاء.csv")
نموذج = KMeans(n_clusters=3)
نموذج.fit(بيانات)

# إظهار المجموعات
print("المجموعات:", نموذج.labels_)
# يمكن الآن تخصيص عروض لكل مجموعة
🎮 التعلم التعزيزي (Reinforcement Learning)

النموذج يتعلم من خلال المكافأة والعقاب (مثل: تعليم الذكاء الاصطناعي لعب الألعاب)

مثال: تعليم وكيل ذكي لعب لعبة الشطرنج - يكسب نقاطاً عندما يفوز ويخسر نقاطاً عندما يخسر

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# إنشاء بيانات بسيطة
x = np.linspace(0, 10, 100)
y = 2 * x + 1 + np.random.randn(100) * 2

# رسم البيانات

plt.title("مثال على بيانات خطية مع تشويش")

plt.ylabel("y")
plt.show()

📊 النتيجة:

رسم بياني يظهر نقاط بيانات خطية مع تشويش. يمكن استخدام هذا المثال لفهم الانحدار الخطي.

كيف نستخدم النتيجة في برنامج؟ بعد فهم العلاقة، يمكننا بناء نموذج انحدار خطي للتنبؤ بقيم جديدة:

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(x.reshape(-1,1), y)
print(f"توقع عند x=5: {model.predict([[5]])[0]:.2f}")
